# Bug: MA-0599 Deva — Spellcasting row renders ZERO real spell chips (unmarked names)

## Overview
Deva Spellcasting (monsters.json actions[2], save (spellcasting), save_dc 17) authors its spell list as plain text. `extractSpellNamesFromSpellcasting` (src/components/encounter/MonsterCardHelpers.js:292-303) only recognizes spell names wrapped in `<strong>`/`<em>` and skips marked text ending in `:` (line 299). Deva marks ONLY the two tier headers plus two mid-prose phrases, so extraction yields the two FAKE names `Concentration` / `Temporary Hit Points` and none of the four real spells → zero real-spell affordances; all four spells (`Detect Evil and Good`, `Shapechange`, `Commune`, `Raise Dead`) are invisible AND ungated (`extractSpellcastingSpellUses` binds `1/Day` to the fake names only). Row named "Spellcasting" renders SpellCastLinks XOR ActionSaveRoll so numeric `spell_save_dc: 17` never renders a save chip (MA-0532). Exact twin of MA-0421/MA-0524/MA-0576 class (headers marked, names plain) with the added §57 fake-chip-from-prose-emphasis variant: a fake-chip click logs a junk zero-adjudication `ability_use` and console.errors.
