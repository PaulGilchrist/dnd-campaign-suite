## Key UI Patterns & Reliable Selectors (run AZ additions)

- Wizard step nav = plain buttons whose `textContent` is `"<n><Label>"` with NO whitespace (`12Resistances&Immunities`) — match via evaluate + `textContent.replace(/\s+/g,'')`; `getByRole name` does NOT match (the number is a separate child node). Step 1 cards are `[data-testid=rules-option-5e|2024]`, `[data-testid=build-mode-custom|quick]`; a ruleset card click AUTO-ADVANCES and detaches the build-mode card (click build mode FIRST, or re-probe after).
- The 5e `validateFeatsStep` over-cap message prints inside the step counter: `Rules allow 0 feat(s) at level 1. You have selected 2 (plus 0 pre-selected feat).` — there is NO `.error-message` strip until a (disabled) Save could fire, so over-cap drafts are silent on the step face except the counter.
- Whole-doc char PUT for over-cap forgeries: `PUT /api/campaigns/<c>/<Name_With_Underscores>.json` (creation normalizes spaces→underscores; `%20` 404s `Character file not found`); body = the FULL char file UNWRAPPED; `feats` is a plain string array on disk, skills live under `skillProficiencies`.
- Map toolbar buttons carry `aria-pressed` (Paint/Erase/Select/Spell/Ruler/Coords/Last Seen/Torchlight); GM sidebar sections are `button.sidebar-section-header` (Maps = manager, board opens ONLY via row `Open "<displayName>"`); visitor sidebar has `Map` (board) but NO `Maps` manager — visitors reach the ACTIVE map only.
- Native-confirm inventory re-check (run AZ): character Delete is still native (`window.confirm`) — always gate any harness acceptance on the DIALOG MESSAGE naming the intended target; `document.title` flips to the clicked sidebar character BEFORE `CharSummary` remounts, so a page-wide `Delete` button locator during the swap window belongs to the PREVIOUS sheet (whose dialog honestly names that previous sheet).

## Quirks / Gotchas (run AZ)

- **Sheet-swap hazard (bit twice, recovered):** after campaign re-select, the auto-mounted sheet is the last-viewed char; a sidebar click updates `document.title` immediately but the sheet content remounts async — pressing header `Edit/Delete` inside that window acts on the OLD sheet. The named native confirm is the ONLY guard (it correctly REFUSED the mismatched target on re-encounter; the first occurrence was blindly accepted and deleted the permanent `AasimarTest` fixture, restored byte-exact from the `dist/campaigns/` twin within the session). Harness law: on a character sheet, scope ALL header-action clicks INSIDE `[data-testid=char-sheet]` AND assert the sheet textContent names the intended char before clicking; for native confirms, read `dialog.message()` and accept ONLY if it names the intended target.
- Wizard create with a 5e quick build auto-applies Class but NOT Subclass — the ladder parks at `Complete "Subclass / Major" first` until you pick one (matches playbook §73).
- The `__map__` change-data key stamps on Maps-manager `Open` (law re-lived) — the map DELETE lane reconciles it to null (re-verified).
