## Key UI Patterns & Reliable Selectors (run BA additions)

- Wizard step-nav buttons: `"<n><Label>"` no whitespace (`7Feats`) — match via `textContent.replace(/\s+/g,'')`. Locked tabs carry `title='Complete "X" first'`; over-cap gate puts the CAUSE in `✓Save`'s title. Subrace selects: `.wizard-step-race select` / `.wizard-step-subrace select` (native `selectOption`). Name field: `//label[contains(text(),"Character Name")]/following::input[1]`.
- Maps-manager rows: aria trio set `Open/Deactivate|Activate/Rename/Edit description for/Dress "<displayName>" with AI/Delete "<displayName>"`. Inline rename input: NO placeholder — locate as the input whose VALUE equals the row's current name; Enter commits. Toolbar create input placeholder: `New map name...` (Enter CREATES).
- Victory chrome: `.victory-banner` (root), buttons by aria-label `Dismiss victory banner` and text `Continue`; `.victory-line` copy rows.
- Clear seam: toolbar button matching `^Clear` → DeleteConfirmModal `.modal-shell-overlay` → `Yes, Clear Board`.
- Attack popups: `.popup-modal` roll face (`Swing 1 of 2`, buttons `Done`/`Cancel attack`) → staged damage face `Done`.
- Overlay census: `g.spell-overlay-layer > g.spell-overlay-group` + red fill circle check.
- API lanes used clean: `POST /maps` (honors displayName, kebab slug, immediate write), `PUT /maps/<slug>/activate|deactivate|rename`, `DELETE /maps/<slug>` (ghost GET 404 = proof), `POST /spell-overlay?campaign=` (NOT under /api), admin clears `POST /api/campaigns/:c/admin/clear-change-data|clear-log`.

## Quirks / Gotchas (run BA)

- **Dialog-brick recovery (NEW recipe, proved):** a native confirm opened INSIDE a `run_code_unsafe` call that gets INTERRUPTED leaves the dialog pending — every later `evaluate`/`screenshot` on that tab HANGS, and `browser_handle_dialog` errors "no related modal state" (the dialog wasn't tracked during an MCP action). Recovery: in `run_code_unsafe` register the acceptor NODE-side (`page.on('dialog', d=>d.accept())` — no page JS needed) then bounded `page.reload()`. ALWAYS `page.removeAllListeners('dialog')` right after — a stale auto-acceptor silently swallows the NEXT confirm (bit once here: it blind-accepted a Delete confirm; the target had been sheet-scoped pre-click so no harm, but the lesson stands: scope targets BEFORE the click, never by dialog text you never read).
- The victory banner is a CLEAR-seam celebration, never a kill-moment one; a kill with no subsequent attack-active Clear = no banner, by design (prep-tidy silence law).
- `lastAttack` first write on a fresh campaign-store: client B's campaign-store stays null until reload (bug file). Don't read cross-client campaign keys in harnesses to mean server truth — GET the API.
- First bucket `currentHitPoints` PATCH after mount paints NO floater (baseline diff), the second does.
- Quick-build wizard: picking race manually suppresses the template subrace default — step 4 blocks with the ladder cause-title until you pick.
