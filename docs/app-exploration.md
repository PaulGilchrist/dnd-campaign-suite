## Known Quirks / Gotchas (XY 2026-11-23 additions; WW-era set below; durable set in playbook)

- Admin clear is NOT client-retiring for Initiative (see bug file): a mounted board looks fully alive after the server store goes `{}`; any Next/Prev click re-persists it. Treat "clear while tabs mounted" as an UNSAFE closeout — always closed-tab two-pass.
- Bucket-404 law on a fresh store: `PATCH /api/campaigns/<c>/<Name>` honestly 404s until the character bucket exists (gameplay creates it); the 404 body is instructive ("create the bucket via POST"). A fetch-loop probe that ignores statuses silently no-ops — read every status in rig code.
- Mount-merge HP seeds are REAL values (EF 130/130, EP 224), not the old 1/1 placeholders — CV-era "1/1 placeholder board" wording is dead.
- A 2024 file flipped to `rules:"5e"` does NOT crash anything: feats missing from the 5e table log `[findFeat] NOT FOUND <name>` (×3 per mount, console.error only) and skip; board + sheet render; class resources silently zero where the 5e table shape differs (bugs filed).
- Cold reload always lands back on campaign-select (no bfcache auto-reselect) — budget a select round-trip in every reload-mid-rig.
- WW-era: `page.waitForFunction` died with `document is not defined`; `setDefaultTimeout` per-page; visitor-origin `PUT <Name>.json` honestly 403s GM-gate (fixed 2026-11-23) while the caster's own-file PATCH lane stays open; byte-safe visitor PUT = re-PUT the exact backup bytes, md5 before/after.
- WW-era: Map DELETE runs a disk-wide strand sweep (`pruneStrandedTokenArt`, fixed 2026-11-23): reclaims the deleted doc's `images/token-*` art plus pre-existing strays, keeps anything a live sibling doc still names; Admin Regenerate inherits; rename never touches art.
