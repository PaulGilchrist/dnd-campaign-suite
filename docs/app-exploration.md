## Known Quirks & Gotchas (live run B)

- `elementFromPoint` on an SVG node serializes `className` as `{}` (SVGAnimatedString) — NEVER read it as null/absent.
- Synthetic `pointerdown` (evaluate-dispatched) makes `setPointerCapture` throw uncaught NotFoundError in `usePlayerDragging.js:207` and abort drag-start; real `page.mouse.down/move/up` works. → backlog try/catch note.
- Playwright CDP `mouse.click({button:'right'})` does NOT fire contextmenu on the map circles here — dispatch `MouseEvent('contextmenu',{bubbles:true})` on the circle instead.
- `performance.getEntriesByType('resource')` under-captures fetch-PUTs — judge map persistence by disk GET, not resource timing.
- Maps "Back" from an editor can land off the Maps list (campaign-select per §95 family) — re-nav Maps + re-select campaign before judging rows "gone".
- Map create: the same `Create Map` button toggles the inline form then submits — clicking it before a name is set is a harmless no-op; after name+radio the trailing click creates.
- Cancel from travel planning deselects the hex-map travel tool (panel unmounts).
- Forced-march budget/camp stale-closure — see `bug-forced-march-camp-budget-stale-closure.md`; treat `travel-dailyBudget` as suspect whenever FM is in play.
- Loaded tabs resurrect 12-player `combatSummary` skeleton via full-store POSTs after admin clears — clear LAST from campaign-select/quiet page (re-proven recipe: `page.goto('/')` then POST clears).
- From run A (still live): final-hex travel advance logs ONE `arrived` row; exhausted-budget advances log nothing until branch resolves; score-cell clicks pop result modal; one SSE per campaign; reload deselects campaign; maps GET shows `displayName:''` (display from `name`).
