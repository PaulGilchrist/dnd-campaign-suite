A lingering `prompt()` on campaign rename means the modal value was discarded (defect, not harness flake). CAMPAIGN-RENAME RESURRECTION HAZARD: after a rename round-trip the in-memory sweep can flush a stale bucket for the OLD name back to disk as a ghost folder (hit live: empty-quests + mid-run log resurrected under the renamed key post-revert, ~1 min later) — always `GET /api/campaigns` folders + `ls public/campaigns/` at cleanup and remove ghosts via the sanctioned `DELETE /api/campaigns/:ghost` (it purges the memory maps so they stay gone).

- Token circles `getBoundingClientRect()` = 0×0 (labels included in group rects) — compute screen cells via `svg.getScreenCTM()` + `p.matrixTransform` (`gx*40+20`).
- Playwright auto-accepts native dialogs and tool output may be injected — a "no confirm / already fixed" claim without a recorded technique does not count.
- Sheet weapon-attack damage commit can be gated behind a post-hit subclass chooser (Stalker's Flurry) — Done alone can look like zero delta.
- `.ct-*` dup banners (factions AND quests) are live-typing (096daddf9).
- Inventory currency keys on disk = pp/gp/sp/cp; GET `/inventory` wraps `{inventory:{…}}`.
- Same-tick display reads after chip clicks can show PRE-balance — judge via disabled states or ≥400ms-delayed GET.
